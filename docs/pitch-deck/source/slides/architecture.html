Architecture

What IndexFi is built on

Web app

Next.js, wagmi/viem and RainbowKit. Create, deposit, redeem and trade from one place.

Price server

Python service streaming 66 live Atlas feeds for the asset browser and charts.

IndexFi contracts

Factory, multi-asset basket vault and preset validator, with Atlas valuation and PancakeSwap route adapters and fixed 10 bps fees.

OpenFour

Core, Registry, standard token and V2 migration library, reused rather than rewritten.

Atlas

On-chain reference NAV for issuance and the opening pool price.

PancakeSwap V2

Executes the basket swaps and hosts the secondary pool.

IndexFi · BNB Bangkok 2026

Reuse first. We use OpenFour’s official Core, Registry, token and migration library, and only write what a basket needs: a custom multi-asset vault, a preset validator and a factory. Atlas provides the on-chain reference price used for issuance; PancakeSwap executes the swaps and hosts the pool. The Python server only displays live Atlas prices: it holds no keys and is never used as an on-chain price source.
