# IndexFi — frontend v2

Local-first Basket A UI; temporary name. Next.js App Router, React, TypeScript, Tailwind CSS, shadcn-compatible CSS primitives, RainbowKit/Wagmi/Viem, TanStack Query. Institutional warm-neutral/orange visual direction inspired by the current Ostium Gateway site; independent original branding.

## Start

```sh
corepack enable
pnpm install
cp apps/web/.env.example apps/web/.env.local
pnpm dev
```

Open http://127.0.0.1:3000. `pnpm test`, `pnpm typecheck`, `pnpm build` are the local validation commands.

## Asset data

- `apps/web/data/commonAssets.ts` is generated by the ignored
  `dump/asset-sync/` pipeline. Do not edit it by hand. It holds the
  Atlas × PancakeSwap BNB Chain catalog and the one selected Atlas feed per
  asset (`ATLAS_FEED_ID_BY_ASSET_ID`, `ATLAS_FEED_IDS`).
  `lib/catalog.ts` adapts it to the domain `Asset` model.
- `apps/web/public/assets/logos/56/<lowercase-address>.png` holds the logos.
- `lib/prices.ts` is the WebSocket client for live prices from the Python
  server (`NEXT_PUBLIC_PRICE_WS_URL`). The protocol is described in the root
  README. The Assets page (`/assets`) shows the catalog, the feed mapping and
  live prices.
- `apps/web/data/pancakeswap-preview.json` is the demo-only display catalog.
- `apps/web/data/testnet-assets.json` stays empty until chain-97 token contracts
  and executable routes are verified. Mainnet metadata is never a transaction
  target on testnet.

## Modes

- `demo` (default): explicit simulated market prices, local paper fills, and local portfolio launch preview. Illustrative creator share allocation and fees, not a financial simulator. Mainnet metadata supplies identity only. No real custody, market reserves, migration, fee earnings or on-chain transactions. State persists in browser storage, not a DB.
- `api`: static verified chain-97 registry, read-only backend portfolio and chart data. All financial writes remain disabled until the verified atomic execution adapter is implemented.

## Product

Explore (default table, card toggle, filters, sorting); Assets (catalog, Atlas feed mapping, live prices); details (NAV, market price, composition, graduation, transparency, USDC swap); five-step Create (identity, composition, allocation, funding, review); My Investments (preview positions, created portfolios, trades). No comparison, Strategy, Smart Basket, direct redemption, or database. Initial USDC funding plus fixed 1 USDC market liquidity. Allocation is buy-and-hold; no artificial constituent cap, subject to contract gas limits. Default chart is 5m; one-minute history contract and optional live point.

## Replaceable design

- `apps/web/styles/tokens.css`: palette, typography, surfaces, shape.
- `styles/layout.css` and `responsive.css`: structural rules.
- `styles/components.css` and `market.css`: presentation and product-specific layout.
- `components/`: page skeleton; `domain/`: financial data structures and preview rules; `lib/`: data adapter and preview state.
- `packages/ui`: reusable semantic primitives, shadcn-compatible variables (not a full generated shadcn component library).

No deployment or public-chain transactions are performed by the frontend.
