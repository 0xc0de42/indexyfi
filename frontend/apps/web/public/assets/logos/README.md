# Asset logos

These images are copied from the `logoURI` values in PancakeSwap's official
extended token list by the ignored `dump/asset-sync/sync_common_assets.py`
pipeline. Files are keyed by chain ID and lowercase token contract address.

Logos and names may be third-party trademarks. Their inclusion is for token
identification and does not imply endorsement. Raw provider payloads and the
matching report remain local under `dump/`. The generated frontend catalog is
`frontend/apps/web/data/commonAssets.ts`, served at `/assets/logos/<chain>/<address>.png`.
